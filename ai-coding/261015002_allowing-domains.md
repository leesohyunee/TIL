# An AI coding session only reaches sites I allow

_2026-10-15 · learned while building seashelly with Claude Code_

## What I learned
My Claude Code session couldn't open a website it needed. The fix was to **add that site's domain to the session's network settings** (the list of allowed domains). After that, it could reach it.

## Why it matters
By default, the agent can't go anywhere on the internet. I decide which sites it can reach, one domain at a time. It's a small safety rail I now know how to adjust.
