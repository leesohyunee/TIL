# Private repos can still fill the contribution graph

_2026-10-02 · learned while setting up my GitHub profile_

## What I learned
Commits in a **private** repo count as green squares only if:

1. The email in the commit (`git config user.email`) is added **and verified** in GitHub → Settings → Emails.
2. **Contribution settings → Private contributions** is turned on (on the profile page, above the graph).

Visitors see the squares but not the private repo's name or code.

## Why it matters
My website repo is private (it has drafts and source files I don't want public), and it still shows my real activity.
